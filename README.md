# Prueba A/A/B: Datos en Decisiones de Producto (App Móvil)

## 📝 Descripción del Proyecto 
Análisis de datos de eventos para una aplicación de venta de alimentos. Realicé un análisis exhaustivo del **embudo de ventas (funnel)** y evalué los resultados de una **prueba A/A/B** para comparar el rendimiento de diferentes variantes de diseño. Se buscaba validar con datos si los cambios propuestos en el diseño de la fuente generaban una diferencia medible en la interacción y conversión de los usuarios. Para proveer *insights* accionables al equipo de Producto y Desarrollo, asegurando que las decisiones de diseño se basen en la evidencia del comportamiento real del usuario, optimizando el *user flow*.

## 🛠️ Habilidades Técnicas
* **Análisis Estadístico:** Prueba A/A/B, Análisis de Significancia.
* **Lenguajes:** Python (Pandas).
* **Análisis de Producto:** Análisis de Embudo (Funnel Analysis), Métricas de Conversión, Análisis de Eventos (Event Data).

## 💡 Hallazgos (Impacto)
* **Impacto en Producto:** Los resultados permitieron al equipo de Producto **descartar o escalar variantes de diseño**, evitando inversiones costosas en desarrollos de bajo impacto.
* **Resultado Clave:** Proporcioné una base de evidencia para las decisiones de diseño, **maximizando la interacción y la tasa de conversión** dentro del embudo de ventas de la aplicación.

## 🏔️ El Reto
El reto fue aislar el impacto de un solo cambio (diseño de la fuente) dentro de un entorno de prueba complejo (A/A/B) y garantizar que cualquier diferencia observada fuera **estadísticamente significativa** y no fruto del azar, validando las conclusiones para la implementación final.
